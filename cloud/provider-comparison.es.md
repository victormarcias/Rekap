# Comparación de Proveedores: AWS vs Azure vs GCP

Mismo servicio, tres nombres distintos — la tabla sirve para traducir entre proveedores sin tener que aprenderse cada ecosistema desde cero.

| Categoría | AWS | Azure | GCP |
|---|---|---|---|
| Regiones disponibles | AWS Regions and Zones | Azure Regions | Google Compute Regions & Zones |
| Cómputo (VMs) | EC2 (Elastic Compute Cloud) | Virtual Machines | Compute Engine |
| Hosting de aplicaciones (PaaS) | Elastic Beanstalk | App Service / Cloud Services | App Engine |
| Cómputo serverless | Lambda | Azure Functions | Cloud Functions / Cloud Run |
| Contenedores (Kubernetes) | ECS / EKS | AKS (Azure Kubernetes Service) | GKE (Google Kubernetes Engine) |
| Auto-escalado | Auto Scaling | Azure Autoscale | Compute Engine Autoscaler |
| Almacenamiento de objetos | S3 | Blob Storage | Cloud Storage |
| Almacenamiento de bloque | EBS (Elastic Block Store) | Managed Disks | Persistent Disk |
| CDN | CloudFront | Azure CDN | Cloud CDN |
| Base de datos SQL / relacional | RDS | Azure SQL Database | Cloud SQL |
| Base de datos NoSQL | DynamoDB | Cosmos DB | Firestore / Bigtable |
| Redes virtuales | VPC | Virtual Network | VPC |
